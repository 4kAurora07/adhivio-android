
Adhivio Android

The native Android rebuild of Adhivio, rewritten in Kotlin for better performance and a more native feel.

Features
Set and manage reminders
Clean, minimal interface
Local notifications
Built natively for Android
Tech Stack
Kotlin
Android Studio
Local notifications API
Getting Started
Prerequisites
Android Studio (latest stable)
Android device or emulator running Android 8.0 or higher
Installation

Clone the repository

git clone https://github.com/4kAurora07/adhivio-android.git

Open the project in Android Studio

Let Gradle sync and resolve dependencies

Run the app on your device or emulator

Status

Work in progress. This is a native Kotlin rebuild of the original Expo based Adhivio app.
